TEMUAN / PERINGATAN
1. Bundle frontend cukup besar (prioritas: sedang)
   Build menghasilkan satu JavaScript chunk sekitar 1.94 MB (gzip sekitar
   580 KB) dan CSS sekitar 1.36 MB (gzip sekitar 244 KB).
   Dampak: waktu muat awal dapat lebih lambat pada koneksi pengguna yang
   terbatas.
   Saran: lakukan code splitting/manualChunks untuk library besar dan muat
   halaman berat secara lazy-load.

2. Data Browserslist kedaluwarsa (prioritas: rendah)
   Build memberi peringatan bahwa caniuse-lite sudah sekitar 8 bulan lama.
   Dampak: target kompatibilitas browser dapat kurang akurat.
   Saran: jalankan "npx update-browserslist-db@latest" pada saat pemeliharaan
   dependensi berikutnya.

3. Log debug masih cukup banyak (prioritas: rendah)
   Ditemukan 58 pemanggilan console.log/console.warn/console.error pada
   frontend dan backend. Sebagian berada pada modul Cetak Surat, misalnya:
   - frontend/src/pages/detailEmployee/components/modalsPrintLetter.jsx
   - frontend/src/pages/detailEmployee/components/footer.jsx
   Dampak: log browser/layanan produksi menjadi ramai dan dapat memuat data
   respons yang tidak perlu.
   Saran: ganti log debug dengan logger terstruktur atau batasi hanya untuk
   mode development.

4. Cetak Surat hanya disembunyikan, belum dinonaktifkan (informasi)
   URL /printLetter masih dapat dibuka langsung oleh pengguna yang mengetahui
   alamatnya. Ini sengaja dilakukan karena permintaan adalah hide sementara.
   Jika fitur perlu benar-benar ditutup, hapus atau beri guard pada route
   /printLetter dan endpoint terkait.
